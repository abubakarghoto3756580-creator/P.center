# Specialists Center for Physiotherapy — Image Request List

Please send the following original, high-resolution images so the website can be updated with real clinic photography. The current website uses **19 synced visual assets**, plus generic avatar icons for doctors without photos. The request below expands this into a complete replacement package for all visible photographic and branded image areas.

## Important instructions for the hospital owner

Please send original files whenever possible. Do not send screenshots, compressed WhatsApp previews, images with text added, or images with watermarks. For doctor portraits, please confirm the correct doctor name with every file. Images should show real Specialists Center staff, clinicians, treatment rooms, or approved official brand assets.

For privacy and consent, please provide only images approved for public website use.
